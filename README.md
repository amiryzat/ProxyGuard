# ProxyGuard

ProxyGuard is a liveness-aware face recognition system for proxy attendance detection, built as a CSC649 final project proposal at UiTM. It solves the problem of one student checking in on behalf of an absent classmate using a photo, video, or replayed face data. On top of standard face recognition, ProxyGuard stacks multiple liveness checks (continuous blink detection, randomized head movement challenges, and randomized voice/word challenges) to confirm the person checking in is physically present and actively responding, not a static image or recording.
